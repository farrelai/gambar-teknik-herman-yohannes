Repository ini berisi dokumentasi dan berkas hasil rancangan teknis instalasi listrik (penerangan dan tenaga) untuk **Gedung Herman Yohannes** (Lantai 1 dan Lantai 2). Proyek ini disusun sebagai pemenuhan tugas akhir mata kuliah **Praktikum Gambar Teknik I**, Semester 1, Program Studi Teknologi Rekayasa Elektro (TRE), Departemen Teknik Elektro dan Informatika, Sekolah Vokasi, Universitas Gadjah Mada (Angkatan 2024).

## Ringkasan Proyek

Perancangan instalasi listrik pada Gedung Herman Yohannes mencakup tata letak titik pencahayaan, saklar (tunggal dan seri), stop kontak berarde untuk peralatan elektronik/komputer dan pendingin ruangan (Air Conditioner), serta Single Line Diagram (SLD) panel distribusi daya. Pembagian grup instalasi dibagi menjadi tiga zona utama pada setiap lantai: **Zona Utara**, **Zona Tengah**, dan **Zona Selatan** guna menjaga keseimbangan beban fasa dan kemudahan pemeliharaan (*maintenance*).
